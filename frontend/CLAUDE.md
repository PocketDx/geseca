# Claude Code en el frontend

Las reglas completas están en AGENTS.md (importado arriba). Lo esencial:

- No tocar `backend/` sin petición explícita.
- Verificar que frontend y backend funcionen entre sí antes de cerrar una tarea.
- No hacer commits, push ni PR sin que el usuario lo pida.
- Peticiones grandes: dividir en tareas y delegarlas a agentes con alcance de
  archivos disjunto.
- Registrar todo cambio en [BITACORA.md](BITACORA.md), incluso los menores.
